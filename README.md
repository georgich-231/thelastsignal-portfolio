# The Last Signal - Unity C# portfolio source

Survival horror game project by Georgi Chorbov. The project README uses the working title **The Names We Leave Behind**.

This portfolio snapshot contains runtime C# scripts from `Assets/WinterPrototype`. It demonstrates gameplay systems including inventory, interaction, player movement, survival mechanics, environmental effects, and story sequences.

## Scope

These are source samples, not a complete runnable Unity project. Scenes, textures, models, audio, third-party asset packs, editor utilities, Unity metadata, and Git history are excluded. The full project remains in the original private repository.

Original repository: https://github.com/georgich-231/thelastsignal

Snapshot: main branch downloaded on 2 October 2026, observed latest commit `d058f72`.

The author confirmed ownership of these runtime scripts and approved public publication. No new software license is assigned by this export.

The C# samples are listed at repository root for easy browsing. MANIFEST.json records their original Unity asset paths.
